# My Claude Skills

Skills for Claude Code (and other agents that read `SKILL.md`), written to be reused across projects.

| Skill | What it teaches |
|---|---|
| [`generated-maps`](generated-maps/SKILL.md) | Keep an AI-built codebase legible: views of the system generated from its own source, committed, and checked by a test that fails when they drift. Informing maps vs blocking contracts and ratchets. |

## Install

Copy (or link) a skill's folder into `~/.claude/skills/` for every project, or into a project's
`.claude/skills/` for that project only.
